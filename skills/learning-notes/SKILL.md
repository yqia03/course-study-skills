# 从资料到完整教材

产物是能教懂未学过本课的学生的教材。读者应能沿着正文理解概念为何需要、推理如何成立、方法为什么这样做，并能解释或解决一个稍有变化的问题。不能把资料扩写、知识点陈述、摘要或练习题堆积当作完成教学。详细意味着补足理解链条，不以字数或标题数量衡量质量。

保留技能名 `learning-notes`，使已有调用继续有效；教材是现在的默认交付标准。

## 默认取向

- 以简体中文为主要讲解语言。知识性标题保留课件的英文标题、标准术语及缩写，采用 **English title（中文释义）**；中文导读另起一句说明本节解决什么问题。允许调整教学顺序，同时保留与原资料章节、页码的对应。自拟补充标题不冒充课件原题。正文术语首次正式介绍用英文加中文括注，后续避免机械重复；“基础补充”“查看解析”等操作标签可用中文。
- 未指定基础时，假定读者会基本算术和简单代数，但不预设理解本课术语及相关线性代数、微积分、概率或编程概念。先用具体对象讲出够用的解释，再在使用位置提供默认折叠的基础补充；详见教学参考。以用户实际指定的基础为准，不无限回溯整门学科。
- 以用户指定的课程范围和资料目录为边界。输入可以是文件夹、若干文件或两者组合；指定文件夹时先递归盘点，不把资料范围预设为课件、转录和 tutorial。阅读材料、书籍节选、题解、实验说明、数据、代码、图像、录音、勘误和其他有用文件都应考虑。没有资料或可解析的目录时请用户提供，不根据文件名或课程名编造教材。
- Transcript（课堂转录）可能包含大量口误、识别错误、漏词或错接句，不能直接当作事实。先判断可用性，再按证据决定采纳、校正或排除；不能只把错误文字润色得更通顺。准确性优先于表面完整，无法可靠确认的内容不进入教学正文。
- 最终教材交付为可直接用浏览器阅读的 **HTML 文件**。按 [HTML、公式与配图](references/html-notes.md) 使用统一模板和构建脚本：正文独立一栏，课程/本章目录合并为默认收起的浮层，提供本次教材范围的离线搜索；跨章节、跨次生成保持同一设计。工作台账不代替教材成品。用户明确另选语言、格式或设计时遵从；读取特殊格式时使用适用工具，不为本地教材另行发布网站。
- **成品默认保存在本次资料目录的 `textbook/` 内，入口为 `index.html`。** 先解析用户指定目录为绝对路径并作为范围根目录；例如 `/课程/lecture5` 的成品是 `/课程/lecture5/textbook/index.html`，章节和资源也在该 `textbook/` 内。持久草稿、提取文件与台账放在根目录内的 `.study-work/`，不得改存父目录或其他工作区。写入前解析 `..` 和符号链接，检查实际目标仍在范围内；用户明确另指定的输出位置除外。若只给若干文件且同处一目录，以该目录为默认根；跨目录输入先确定输出根，不自动选择公共父目录。附件与多章规则见 HTML 参考。
- 不因缺少目标字数、评级偏好或排版偏好而停工；采用本技能默认值。只有确实影响内容正确性的缺失信息才需要澄清。

## 与作业 skill 交接

生成教材时阅读 [教材索引与复用](references/textbook-handoff.md)，在教材目录生成轻量的 `textbook-index.json`：记录范围、章节锚点、来源指纹及未解决缺口，供 `kill-your-quizs` 按需读取。索引是导航与来源状态记录，教材正文仍是主要交付物；不另写一份重复正文的 Markdown。单独安装本 skill 也能生成完整教材。

更新已有教材时，先盘点当前范围，比较原资料与已有来源记录；复用经核对仍适用的章节，集中读取新增、变更、缺口及受影响的内容。文件指纹一致只说明文件未变，不代替内容审阅。旧教材不是新的独立证据；来源无法追溯或教学不足的部分仍需回查、补写。保持本次授权范围完整，不借“复用”省略尚未处理的资料。

## 先盘点资料，再设计教学

1. **遍历并筛选。** 写大纲和正文前阅读 [资料处理规则](references/source-handling.md)，使用 `scripts/inventory_materials.py` 或等效完整遍历，建立文件级清单。先发现全目录，再按内容判断各文件的用途、版本和相关性。扫描成功不等于已读；不按扩展名白名单、文件名或前几个搜索结果限定资料。记录采用、无关、重复、不可读和待确认的原因。
2. **阅读并核验。** 读取所有相关资料的有效范围，检查补充说明、勘误及跨文件引用，再确定章节。转录先判断整体与片段可用性；各类资料均按内容证据处理冲突。仅部分内容相关的大文件要说明采用范围。不可读内容作为缺口，错误片段不得为凑齐覆盖重新引入。
3. **建立教学地图。** 在范围内的 `.study-work/` 维护“英文标题/术语 → 可靠来源 → 前置依赖 → 教材章节 → 完成状态”。盘点定义、机制、公式、条件、方法、图表、例题和例外，合并重复但保留独有的有效信息。用课程目标和学生基础确定主线；调整顺序后仍能按原英文名称定位知识。
4. **逐章教会。** 写作前阅读 [教学展开方式](references/teaching-patterns.md)。从问题和必要基础开始，按依赖关系展开解释与示范，让学生经历从不懂到能理解、能尝试的过程，再回看来源核对覆盖。章节间写出过渡；后半部分、附录和低评级内容也要有相称的解释。

当空间关系、结构、流程、几何或数据变化通过图像更容易理解时，把配图融入对应知识块。优先使用上传资料中准确且可读的原图，可用截图、页面渲染或图像提取工具取得；原图不适合讲解时，可自行绘制有依据的教学示意图。配图要说明“看哪里、说明什么”，并按 HTML 参考中的规则保留来源、标识自绘内容和检查显示效果。

## 每个知识块如何讲清楚

“知识块”是可以单独命名和理解的概念、原理、方法或一组不可分割的子步骤。正文中的每个知识块都要有标题、重要性及具体理由，并把来源定位放在相邻位置或段末。

根据知识性质安排叙述，不机械复制固定栏目。讲解应让初学者能够回答：

- **学它解决什么问题？** 用具体情境建立动机，指出它与前面知识的连接。
- **它究竟是什么意思？** 先用日常语言建立直觉，再给准确术语、定义或表述。避免用另一个未解释的术语解释当前术语。
- **为什么成立、怎样发生或怎样操作？** 补出关键因果环节、推导和判断依据，不能把“显然”“同理”“代入即可”用来跳过初学者需要的步骤。资料未提供足以支持结论的论证时，说明其依据和局限。
- **具体用起来是什么样？** 对抽象、程序性或容易误解的内容给出完成的例子，展示必要中间过程并解释结果。原资料的教学例子要解释其作用；自拟例子标注“教学示例”。
- **何时适用，哪里容易混淆？** 解释条件、边界、反例或常见误解；以资料为基础，不为凑栏目编造所谓“老师强调的易错点”。

同章尽量贯穿一个简单例子，一次引入当前需要的新东西。用具体的人、物、数字或动作承载术语，逐步交代“已知什么、要解决什么、为何做这一步、得到什么”。一句话承担一个主要意思；详细程度以读者能接上推理为准。写作尺度参考教学文件中的邮件打分示范。

公式、流程、概念辨析或论证需要展开时，阅读 [教学展开方式](references/teaching-patterns.md) 中相关部分。简单事实无需硬凑推导和例题。类比用于引入直觉，随后说明准确含义及类比边界。

公式保留规范数学排版，包括分式、上下标、向量、矩阵、分段、对齐关系及有用的原编号。公式旁用简体中文解释符号与步骤；不能将数学结构压成普通文字，或留下未渲染的 LaTeX。具体渲染与降级处理见 HTML 参考。

每个核心知识块在讲解及完整示范后，给一句白话记忆线索和一个理解检查，例如改变一个条件或解释原因；解析默认折叠。简单事实无需机械出题。正文中的新知识、公式解释、完整示范及“为什么这样做”直接展开；只有既有基础的详细补充和练习提示/答案默认折叠。即使不展开基础补充，正文也须保留最低限度的解释。

## 重要性评级

评级衡量该知识对**理解和应用当前课程**的作用。采用以下五级，不强行拉开分布；一章有多个核心点是正常的。

| 评级 | 含义 | 判断依据 |
|---|---|---|
| ★★★★★ · 5/5 核心基础 | 必须学懂的主干 | 是课程核心问题、基本原理，或多个后续知识依赖的基础 |
| ★★★★☆ · 4/5 重要方法 | 应能解释并应用 | 主要方法、关键应用，或直接影响正确使用核心知识的条件 |
| ★★★☆☆ · 3/5 理解支撑 | 应理解其作用 | 支撑主干的细节、解释、比较，或较局部的应用 |
| ★★☆☆☆ · 2/5 局部拓展 | 认识并理解适用处 | 特殊情境或延伸内容，对本课主线依赖较少 |
| ★☆☆☆☆ · 1/5 背景补充 | 知道它在讲什么 | 历史、背景或旁支信息，缺少它通常不妨碍理解主线 |

- 格式示例：`重要性：★★★★★ · 5/5｜理由：后续加权平均与方差的解释都依赖对“每个观测值”的理解。` 理由应针对本块，不能反复只写“很重要”。
- 独立的新概念不能只继承章首评级。仅用于说明某概念的例题、图示和步骤可沿用所属知识块的评级；若引入独立方法，应另行评级。
- 低评级不等于删除或只列名称；仍需解释到读者能够理解，只是按实际复杂度控制展开。安全条件、适用边界或容易导致错误的例外，可能值得高评级，不因处于附录而降低。
- 结合学习目标和知识依赖判断，不凭页数、重复次数、教师语气或难度打分。额外补入的独立前置知识也需评级，并标明“前置补充”。
- 教师明确强调或明确给出的考核范围另作来源说明。评级不代表考试概率，不得自行称为“必考”。只有局部材料时说明评级仅基于当前范围，无法判断的地方注明依据有限。

## 来源与可靠性

- 保留读者可查回的相对文件路径与实际位置，例如 `［readings/章节.pdf，第 8–10 页；audio/转录.txt，12:30–14:05］`。表格、代码、网页或题解使用对应工作表、单元格、行号、章节或题号。没有原始定位时可添加段落编号并说明，不伪造页码或时间戳。
- 清楚区分资料内容、为理解补充的解释或示例，以及未解决的疑问。为整段补充统一标注即可，不必给每句都贴标签。
- 若资料存在错误、矛盾、缺页、模糊图表或疑似转录错误，按资料处理规则核查。正文只采用可靠或有据校正的知识；未解决的疑点仅列入文末资料限制，不将错误原句或猜测的修正版本编成教学结论、例题、图示或理解检查答案。
- 外部查证仅用于必要补充或核实；需要时使用可靠原始来源并给链接，明确这是外部补充。不能把外部课程内容当作当前老师已经讲授的内容。用户限定只用所给资料时，保留无法解决的疑点并遵守范围。

## 交付与完成检查

教材通常包括：学习目标与必要基础、可点击目录、按依赖顺序展开的章节、完整示范与适量练习解析，以及简明来源覆盖表和资料限制。每章围绕能解决的问题组织，并指出它与前后章节的关系。范围说明、评级图例和来源附录从简，教学正文是主体；覆盖表按自然主题映射，不必为每句创建表格行。

长资料按自然章节写入 HTML，必要时拆为多个 HTML 章节文件并给一个可点击的总目录；相关图像及渲染资源随笔记交付。持续维护覆盖台账和剩余范围。分批处理仍要完成全部已授权范围，不能把剩余章节降格为提纲或让用户逐章请求“继续”。确有读取或输出限制时，明确已完成范围、缺口及后续入口，不宣称全部完成。

交付前进行内容审阅，而非只检查格式：

- **资料完整性：** 已遍历指定目录与子目录，文件级清单无未解释的遗漏；所有有用资料已实际读取、整合或记录缺口，自己的旧产物没有被当作新的独立证据。每个可靠知识点都有实质性讲解，错误片段的排除不算漏讲或已讲解。
- **教学有效性：** 抽查最难处和末尾章节：每个抽象词能否指向具体对象？学生能否解释两步之间的原因、为何选此方法、改变条件会怎样？记忆线索是否说明关系而非重复术语？若只能复述定义，应补具体缺环。确认核心推理没有藏进基础补充或答案里。
- **评级：** 每个独立知识块有统一尺度的评级和具体理由；教师强调、考核信息与学习价值没有混为一谈。
- **准确性：** 核对公式、单位、数字、代码或论证；来源定位真实，补充内容有标记，冲突没有被悄悄抹平。回查被排除的转录信息，确保未通过摘要、例题、图注、评级理由或答案再次进入笔记；转录可用性与知识重要性分别判断。
- **表达：** 去掉同义重复和空洞总结，保留理解所需的细节；标题与目录能帮助学习者顺着读下去。
- **呈现：** 目录默认收起，展开/关闭不挤压正文；基础补充和解析默认收起，核心讲解可见。标题与原英文资料可对照，英文、缩写、中文和正文关键词能搜索定位；拆章索引覆盖本次教材。实际检查桌面、窄屏、公式及图像，不仅凭源码宣称视觉验证通过。
- **保存位置与交接：** 确认最终入口、章节、资源和索引实际位于范围根目录的 `textbook/` 内，或用户明确指定的输出位置；索引指向存在的章节锚点，来源映射和覆盖状态与成品一致，交付链接指向该成品。写入受限时按环境规则处理所需权限，不静默改存工作目录，也不把临时预览当作最终交付。

最终告知教材入口和实际处理范围；有缺口时直说。保留原始资料，工作文件与教材产物分开；不另外输出冗长的制作日志。
