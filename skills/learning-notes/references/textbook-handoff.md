# 教材索引与作业复用

生成或更新教材时阅读。教材保持完整的教学正文；另外生成一个紧凑索引，让 `kill-your-quizs` 能查到相关知识块，不必重新读取整套课件或 HTML 内嵌的搜索全文。

## 目录约定

```text
lecture5/                    本次范围根目录
├── lecture.pdf              原资料保持原样
├── textbook/
│   ├── index.html           默认教材入口
│   ├── textbook-index.json  供 agent 查阅的轻量索引
│   ├── chapters/            拆章时使用
│   └── assets/              需要外部图片、字体等时使用
├── .study-work/             本次草稿、提取文件与构建清单
└── submit/                  作业 skill 的必要提交文件
```

只创建实际需要的目录。用户指定 `lecture5/` 时，不能把教材、索引、草稿或答案建在其父目录。多个章节的“完整教材”也只覆盖本次授权范围；若用户指定整门课程目录，才以该课程目录为根。读取用户另行指定的共享教材不改变本次写入边界。

已有旧位置的教材可继续读取。用户要求更新时采用默认新目录或其指定位置，保留旧成品，明确交付新入口；不把旧教材当成独立原始证据。原资料曾存放于 `textbook/` 时，也必须保护，不能仅凭目录名覆盖或排除。

## 构建交接信息

按 [HTML 构建方式](html-notes.md) 编写正文，并在 `.study-work/catalog.json` 写入已实际核对的来源映射。例如以下示例描述一份仍有资料缺口的教材：

```json
{
  "coverage": "partial",
  "limitations": ["lecture.pdf 第 9 页的图表模糊，尚不能确认该例的数值"],
  "sources": [{"path": "lecture.pdf"}],
  "section_sources": {
    "index.html#conditional-probability": ["lecture.pdf"],
    "index.html#bayes": ["lecture.pdf"]
  }
}
```

`sources[].path` 相对范围根目录；`section_sources` 的键是输出页面相对教材目录的路径加真实锚点，值为该知识块实际使用的来源路径。正文继续保留页码、行号、时间戳、适用条件，以及校正和外部补充的身份；来源数组不能替代这些定位。章级公共假设和各个小节分别映射自己的依据，不机械地给所有章节挂上所有文件。

将 `--catalog <范围根目录>/.study-work/catalog.json` 传给构建脚本。脚本从真实文件计算 SHA256，从正文标题提取章节与别名，输出 `textbook-index.json`。正文、构建清单和本地来源须在 `--scope-root` 内；用户提供了范围外输入时，先明确其授权位置，必要时在范围内保留有记录的输入副本，不通过扩大根目录绕开边界。

覆盖范围确已完成时设 `coverage: complete`；存在未处理或影响教学的缺口时设 `partial` 并写明缺口。默认是 `partial`。没有可追溯本地来源的知识块保留空映射，在正文标明依据与限制；外部来源保留可靠链接，不编造本地文件。构建成功仅代表格式与路径检查通过，内容审阅和浏览器检查仍按主技能完成。

## 索引契约 v1

生成的索引包含：

- `schema_version: 1`、`generated_by: "learning-notes"`。
- `entry`：入口相对索引目录的路径；`scope_root`：范围根目录相对索引目录的路径，默认是 `..`。
- `coverage` 与 `limitations`：本次范围的完成状态和已知缺口。
- `pages`：页面相对路径和 SHA256，绑定索引与当前教材版本。
- `sources`：来源相对范围根目录的路径和 SHA256。
- `sections`：页面 `path`、`anchor`、`title`、`aliases` 和引用来源数组的 `source_ids`。

索引不复制正文、题目答案或个人身份。读取方只检查匹配页面与相关来源的指纹；指纹未变不意味着事实可靠，教材缺口也不要求重做与当前问题无关的内容。

修改教材正文或原资料后，重新核对受影响章节并重建索引；仅对当前文件重新计算指纹不能替代核验。更新时继续完整盘点本次范围，以发现新增资料、勘误和未被旧索引覆盖的内容。
